# ReaProfessor theme

`ReaProfessor.ReaperTheme` is a **color overlay** on Default 7.0 imagery — faster to iterate than forking hundreds of PNGs.

## Setup

```bash
./tools/unpack_default_theme.sh
./tools/link_to_reaper.sh
```

Then in REAPER: **Options → Themes → ReaProfessor**.
